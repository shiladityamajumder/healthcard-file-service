# Changelog

## 1.0.0 - 2026-08-04

- Initial NestJS file service.
- Exact mappings for `platform.file_objects`, upload sessions, variants, and access events.
- Controlled domain associations based on verified SQLAlchemy models.
- Public/private S3 workflows.
- Server-side and presigned uploads.
- Replacement, deletion, bulk deletion, image variants, health checks, Swagger, Pino, Docker, and tests.
- No database migrations or automatic schema synchronization.
